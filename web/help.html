从音乐到时间线

拍点工坊在你的电脑上分析音乐，生成 Final Cut Pro 可以继续编辑的卡点时间线。所有媒体留在本机。

五步开始

  1. 导入音乐，或点击“演示项目”。第一次分析可能需要数十秒初始化。
  2. 试听节拍。出现半速 / 倍速识别时，点击 BPM 下方的 ×2 / ÷2 重新跟踪；固定节奏也可手动输入 BPM 和首拍。
  3. 点击波形定位，拖动标记微调；Shift 点击新增，Delete 删除。选中标记后可禁用或强制换镜。
  4. 按需缩短音乐、添加镜头，设置每镜头拍数和节奏曲线，点击“生成编排”。
  5. 导出后，在 FCP 里选择“文件 → 导入 → XML”，打开 timeline.fcpxml。可先在测试资源库中验证。

音乐缩短怎么用

填写目标长度与允许误差，查找候选，再选择一种。候选保留音乐的开头和结尾，移除中间若干完整的 4 拍分组。相似度用于比较接缝附近的音色，请使用“试听剪后音乐”亲自检查接缝。

素材长度与首尾固定

镜头按列表或随机顺序循环。可指定第一与最后一个素材。素材的入点与出点限制可用范围；如果不够长，程序会提示减少拍数或添加长素材，不会自动拉伸视频。图片会在导出时生成静态 MOV。

保存与迁移

Mac App 的“保存”会弹出系统保存窗口；JSON 保存标记与剪辑设置，不包含媒体。App 数据位于 ~/Library/Application Support/BeatCut Studio，其中 media 是素材，exports 是导出文件。源码网页版使用项目目录下的 .data。

请保留对应的数据目录。跨电脑分享剪辑时，在 FCP 中整合媒体；单独分享 XML 或 JSON 不会携带音乐和镜头。

当前限制

0.1.0 提供音乐试听与镜头编排示意，完整视频播放、调色、转场和最终渲染在 FCP 完成。当前默认 SDR Rec.709，HDR / Log 请在 FCP 做正确色彩处理。复杂变速音乐需要人工修正。4 拍分组不是歌曲段落或小节强拍的自动识别。
