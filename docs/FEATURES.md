# 0.1.0 功能范围

本项目独立实现音乐驱动的标记与粗剪工作流，采用 MIT 许可证。

| 功能 | 当前实现 |
| --- | --- |
| 自动节拍 / BPM | librosa 动态规划节拍跟踪，支持指定 BPM 重新分析 |
| 标记管理 | 波形拖动、新增、删除、忽略、强制剪切、撤销 |
| 手动节拍 | 首拍偏移 + BPM 等距网格 |
| 音乐时长 | 连续区间或保留首尾的单次中段移除候选 |
| 拼接试听 | 实际 PCM 拼接，使用与导出相同的帧量化区间 |
| 镜头管理 | 视频 / 图片、排序、入出点、首尾固定、fit / fill |
| 速度曲线 | 均匀、渐快、两头快、起伏；改变换镜间隔，不改变视频播放速度 |
| 排列策略 | 列表循环 / 固定种子随机循环；固定首尾素材从中段候选排除，有其他素材时不复用首尾 |
| FCP 导出 | FCPXML 1.10，音乐标记 / gap 占位 / 真实素材三种模式 |
| 辅助导出 | WAV、CSV、项目 JSON |
| Mac App | 独立原生窗口、原生打开 / 保存、菜单快捷键、内置分析引擎与 FFmpeg |
| 编辑项目 | 同一素材库中的保存、打开和复制 JSON 另存 |

未实现：已有 FCPXML 往返编辑、转场模板、连续变速、音乐语义段落识别、自由速度跟踪、视频合成预览、最终 MP4 渲染、公证 macOS 安装包、跨电脑媒体重链接界面。

音乐拼接候选的相似度是接缝附近的频谱相似度，不是质量置信度。帧位置使用 Fraction，视频序列连续覆盖选定音乐。音频裁切采用累计样本舍入，让 WAV 与时间线长度差不超过一个采样点。
